# 营养质量控制指标监测 - 指标规格

> 以下指标规格基于《14.营养质量控制指标监测管理制度.docx》。
> 由于文档为二进制格式无法直接解析，以下规格从用户需求规格中提取。
> 标记为"待确认"的项目需要与制度原文逐项核对。

---

## 1. 肠内营养中断率 (enteralInterruptionRate)

- **公式**: 肠内营养中断事件数 / 肠内营养患者日 × 100%
- **分子**: csList 包含 "J" 或 cs="J" 的记录（暂停肠内营养事件）
- **分母**: 同期接受肠内营养的患者日数
- **目标值**: <10% (待确认)
- **比较方式**: LT
- **去重粒度**: patient_day（同一患者同一天多次暂停计为一次中断事件，需状态变化去重）
- **数据源**: 肠内营养记录单
- **当前状态**: 待确认具体去重规则和分母定义

## 2. 肠内营养计划完成率 (enteralPlanCompletionRate)

- **公式**: 完成目标量的患者日数 / 有目标量的患者日数 × 100%
- **分子**: 完成量 >= 目标量的记录数
- **分母**: 目标量非空且有效的记录数
- **目标值**: ≥80% (待确认)
- **比较方式**: GE
- **去重粒度**: patient_day
- **数据源**: 肠内营养记录单
- **当前状态**: **mapping_required** - 目标量和完成量字段未确认

## 3. 喂养管堵管发生率 (feedingTubeBlockageRate)

- **公式**: 堵管事件数 / 喂养管日 × 100%
- **分子**: 堵管事件（需通过机械性并发症字段判定）
- **分母**: 同期喂养管留置日数
- **目标值**: <5% (待确认)
- **比较方式**: LT
- **去重粒度**: event（连续堵管状态去重）
- **数据源**: 肠内营养记录单 + tubeExe
- **当前状态**: **mapping_required** - 机械性并发症字段未确认

## 4. 喂养管非计划拔除发生率 (feedingTubeUnplannedRemovalRate)

- **公式**: 非计划拔除事件数 / 喂养管日 × 100%
- **分子**: 非计划拔除事件
- **分母**: 同期喂养管留置日数
- **目标值**: <3% (待确认)
- **比较方式**: LT
- **去重粒度**: event
- **数据源**: tubeExe
- **当前状态**: 需复用 tubeExe 数据

## 5. 喂养管相关皮肤问题发生率 (feedingTubeSkinProblemRate)

- **公式**: 皮肤问题事件数 / 喂养管日 × 100%
- **分子**: 喂养管相关皮肤问题事件
- **分母**: 同期喂养管留置日数
- **目标值**: 12% (待确认比较方式)
- **比较方式**: DISPLAY_ONLY
- **去重粒度**: event
- **数据源**: 肠内营养记录单
- **当前状态**: **mapping_required**

## 6. 误吸发生率 (aspirationRate)

- **公式**: 误吸事件数 / 肠内营养患者日 × 100%
- **分子**: 误吸事件
- **分母**: 同期接受肠内营养的患者日数
- **目标值**: <5% (待确认)
- **比较方式**: LT
- **去重粒度**: event
- **数据源**: 肠内营养记录单
- **当前状态**: **mapping_required**

## 7. 喂养不耐受发生率 (feedingIntoleranceRate)

- **公式**: 喂养不耐受事件数 / 肠内营养患者日 × 100%
- **分子**: zf > 阈值 或 并发症事件
- **分母**: 同期接受肠内营养的患者日数
- **目标值**: <20% (待确认)
- **比较方式**: LT
- **去重粒度**: patient_day
- **数据源**: 肠内营养记录单
- **当前状态**: 需确认阈值

## 8. 肠内营养与肠外营养比 (enteralParenteralRatio)

- **公式**: 肠内营养患者数 / 肠外营养患者数
- **分子**: 同期接受肠内营养的患者数
- **分母**: 同期接受肠外营养的患者数
- **目标值**: ≥2:1 (待确认)
- **比较方式**: GE
- **去重粒度**: patient_month
- **数据源**: drugExe (复用现有 NutritionService 口径)
- **当前状态**: 复用现有 EN/PN 统计
